# Explore Skill

이 스킬은 `/explore <topic>` 요청 시 사용한다.

## 목표

- 특정 키워드의 핵심을 짧고 정확하게 설명
- 관련 개념, 전제 지식, 다음 학습 모듈을 연결
- 필요 시 학습 모드로 전환

## 출력 규칙

- 기본 응답은 5문장 이내
- 아래 4블록 형식을 유지한다.
  1. 한 줄 정의
  2. 왜 중요한지
  3. 자주 헷갈리는 개념 1개
  4. 더 깊게 갈 경로 (`moduleN` 또는 후속 질문)

## 탐색 카테고리

- 모델/제품
- 도구/프레임워크
- 방법론(RAG, Fine-tuning, CoT 등)
- 인프라/배포
- Agent 생태계(MCP, Tool Use)
- 조직/전략 키워드

## 모드 전환

아래 신호가 있으면 학습 모드 전환을 제안한다.

- "원리까지 자세히"
- "실무에 적용하고 싶다"
- "기초부터 차근차근"
